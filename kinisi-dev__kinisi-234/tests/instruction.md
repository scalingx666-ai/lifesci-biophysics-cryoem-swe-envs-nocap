# Issue

**Title:** Fix the intercept to zero when fit_intercept=False

## Description

`bayesian_regression` always sampled `[gradient, intercept]`; `fit_intercept=False` only skipped storing the intercept. The gradient was therefore always fitted with a free intercept, and `posterior_predictive` failed on `self.intercept.unit`. With the flag off, only the gradient is now sampled, the intercept is fixed at 0, and `posterior_predictive` handles `intercept=None`.

**Tests:** `test_diffusion.py::test_bayesian_regression_without_intercept`.
