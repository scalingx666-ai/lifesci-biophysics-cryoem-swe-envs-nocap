### [`v4.1.1`](https://redirect.github.com/pypa/cibuildwheel/releases/tag/v4.1.1)

[Compare Source](https://redirect.github.com/pypa/cibuildwheel/compare/v4.1.0...v4.1.1)

- ✨ Adds `pyodide-build` as a separate [`build-frontend`](https://cibuildwheel.pypa.io/en/stable/options/#build-frontend), now the default frontend for Pyodide, with verbosity flags handling. Any other frontend is ignored with a warning on Pyodide. (, )
- 🔐 Uses digests instead of tags for pinned container images, strengthening supply-chain security. The human-readable tags remain as comments in `pinned_docker_images.cfg`. ()
- 🐛 Fixes platform-specific [`test-runtime`](https://cibuildwheel.pypa.io/en/stable/options/#test-runtime) environment variables (e.g. `CIBW_TEST_RUNTIME_ANDROID`) not being honored ()
- 🐛 Fixes quoting of [`test-requires`](https://cibuildwheel.pypa.io/en/stable/options/#test-requires) and [`audit-requires`](https://cibuildwheel.pypa.io/en/stable/options/#audit-requires) so PEP 508 specifiers containing spaces work ()
- 🐛 Makes [`archs`](https://cibuildwheel.pypa.io/en/stable/options/#archs) parsing case-insensitive and platform-aware, so e.g. `arm64` works on Windows ()
- 🐛 Uses an absolute path for the `{project}` placeholder in [`config-settings`](https://cibuildwheel.pypa.io/en/stable/options/#config-settings) ()
- 🐛 Validates the [`pyodide-version`](https://cibuildwheel.pypa.io/en/stable/options/#pyodide-version) option against the build identifier with a clear error ()
- 🐛 Fixes PyPy installs on macOS after PyPy switched its downloads from `.tar.bz2` to `.tar.gz` ()
- 🐛 Makes a matching `python3-config` available in the build and test venvs on macOS ()
- 🛠 Updates dependencies and container pins (, , )
- 🛠 Updates Android tests to current Python versions and the new test repository URL ()
- 🛠 Drops the `orjson` dependency, no longer used by mypy 2+ ()
- 📚 Builds the docs with properdocs, a MkDocs fork ()
- 📚 Adds the missing `cp314-pyodide_wasm32` entry to the build identifier table ()
- 📚 Removes outdated notes about the `pip wheel` build frontend and ClearLinux ()
- 💼 Adds a "CI: PyPy EoL" PR label to run PyPy EoL tests on PRs ()
- 💼 Updates CI action pins and pre-commit hooks (, , , , , )
