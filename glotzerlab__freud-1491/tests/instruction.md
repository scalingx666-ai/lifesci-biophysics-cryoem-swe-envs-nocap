### zizmor notes

#### Enhancements 🌱[🔗](https://docs.zizmor.sh/release-notes/#enhancements)

- The [typosquat-uses](https://docs.zizmor.sh/audits/#typosquat-uses) audit now supports pre-commit config inputs ()

- The [self-hosted-runner](https://docs.zizmor.sh/audits/#self-hosted-runner) audit is now significantly more precise ()

  Many thanks to [@&#8203;ubiratansoares](https://redirect.github.com/ubiratansoares) for proposing and implementing this enhancement!

- The [dangerous-triggers](https://docs.zizmor.sh/audits/#dangerous-triggers) audit now considers the issue_comment trigger fundamentally dangerous ()

- zizmor is now aware of the image_version workflow trigger ()

- The [dangerous-triggers](https://docs.zizmor.sh/audits/#dangerous-triggers) audit now produces more precise finding/diagnostic spans ()

- The [cache-poisoning](https://docs.zizmor.sh/audits/#cache-poisoning) audit is now aware of [pnpm/setup](https://redirect.github.com/pnpm/setup) ()

- The [unpinned-images](https://docs.zizmor.sh/audits/#unpinned-images) audit now produces more precise findings when the user's workflow contains an indirect matrix ()

  Many thanks to [@&#8203;ubiratansoares](https://redirect.github.com/ubiratansoares) for proposing and implementing this enhancement!

- The [cache-poisoning](https://docs.zizmor.sh/audits/#cache-poisoning) audit is now aware of GitHub's new cache-mode: setting, and will skip any findings that would occur when a job has an effective cache-mode: none ()

- The [cache-poisoning](https://docs.zizmor.sh/audits/#cache-poisoning) audit now flags usages of cache-mode: write and cache-mode: write-only with dangerous triggers, i.e. triggers that give an attacker privileged code execution ()

- zizmor now uses a tree-sitter grammar for PowerShell that's more precise/capable of capturing more non-trivial PowerShell expressions ()

#### Bug Fixes 🐛[🔗](https://docs.zizmor.sh/release-notes/#bug-fixes)

- Fixed a class of false positives/imprecisions in [adhoc-packages](https://docs.zizmor.sh/audits/#adhoc-packages) that caused some pnpm and yarn invocations to be misclassified as package installations ()

  Many thanks to [@&#8203;marcalexiei](https://redirect.github.com/marcalexiei) for implementing this improvement!

- Fixed a bug where zizmor would fail to honor Git submodules and worktrees when discovering configuration files relative to a repo root ()

- Fixed a bug where the [ref-version-mismatch](https://docs.zizmor.sh/audits/#ref-version-mismatch) audit would crash on unusually placed version comments ()

- Fixed a bug where zizmor would fail to handle some pre-commit inputs that use prek extensions to the language_version and default_language_version keys ()

- Fixed a bug where the [use-trusted-publishing](https://docs.zizmor.sh/audits/#use-trusted-publishing) audit would fail to detect certain true-positive patterns inside of PowerShell blocks ()
