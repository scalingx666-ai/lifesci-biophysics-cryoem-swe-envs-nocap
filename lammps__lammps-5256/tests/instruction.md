# Issue

**Title:** Add feature to distribute unit tests across multiple NVIDIA GPUs

## Description

**Summary**

With enabled GPU support, parallel tests may be dispatched to different NVIDIA GPUs through the resource allocation feature of CTest and the CUDA_VISIBLE_DEVICES environment variable. Every test requests one slot of a "gpus" resource, and a launcher script sets the environment variable accordingly.  Available GPUs are listed in a resource spec file, which is generated from the output of nvidia-smi if it does not exist. Without a resource spec file, the tests run the same way as without this feature.
