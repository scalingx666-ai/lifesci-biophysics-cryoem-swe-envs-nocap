### [`v3.4.1`](https://redirect.github.com/pypa/cibuildwheel/releases/tag/v3.4.1)

[Compare Source](https://redirect.github.com/pypa/cibuildwheel/compare/v3.4.0...v3.4.1)

- ⚠️ Building for the experimental CPython 3.13 free-threading variant is now deprecated. That functionality will be removed in the next minor release. The [`enable`](https://cibuildwheel.pypa.io/en/stable/options/#enable) option `cpython-freethreading` is therefore also deprecated. Builds specifying `enable = "all"` no longer select `cpython-freethreading`. CPython 3.14 free-threading support remains available without the `enable` flag. ()
- 🐛 iOS builds will no longer skip `repair-wheel-command` if it's defined in config ()
- 🐛 Fix bug causing `uv` to fail when environments define PYTHON\_VERSION or UV\_PYTHON, conflicting with our venvs ()
- ✨ cibuildwheel prints the selected build identifiers at the start of the build. ()
- 🔐 The GitHub Action now references other actions with a full SHA ()
