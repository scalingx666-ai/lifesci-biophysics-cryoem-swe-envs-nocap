### Release Notes

<summary>pypa/cibuildwheel (pypa/cibuildwheel)</summary>

### [`v3.4.0`](https://redirect.github.com/pypa/cibuildwheel/releases/tag/v3.4.0)

[Compare Source](https://redirect.github.com/pypa/cibuildwheel/compare/v3.3.1...v3.4.0)

- 🌟 You can now build wheels using `uv` as a build frontend. This should improve performance, especially if your project has lots of build dependencies. To use, set [`build-frontend`](https://cibuildwheel.pypa.io/en/stable/options/#build-frontend) to `uv`. ()
- ⚠️ We no longer support running on Travis CI. It may continue working but we don't run tests there anymore so we can't be sure. ()
- ✨ Improvements to building rust wheels on Android ()
- 🐛 Fix bug with the GitHub Action on Windows, where PATH was getting unnecessarily changed, causing issues with meson builds. ()
- ✨ Add support for quiet setting on `build` and `uv` from the cibuildwheel `build-verbosity` setting.
- 📚 Docs updates, including guidance on using Meson on Windows ()
