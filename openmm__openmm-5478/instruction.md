# Issue

**Title:** Fix Quantity * Quantity and / Quantity on compound ratio units

## Description

## Summary

.

`Quantity.__mul__` delegated `Quantity * Quantity` to `(Quantity * scalar) * unit`, and `__truediv__` mirrored it. When `self`'s unit is a dimensionless compound ratio such as `nanometer/angstrom`, the scalar half collapses the unit to dimensionless and returns a bare value, so the following unit operation sees only the other operand's unit:

```python
a = 3.0 * (nanometer / angstrom)
a * a   # was "9.0 nm/A", now 900.0, matching a ** 2
a / a   # was 0.1, now 1.0
a / b   # was 15.0 for b = 2.0 A/nm, now 150.0
```

The fix multiplies or divides the raw values and combines both units in a single `Quantity` before `reduce_unit`. Operating on raw values also preserves the previous float association for ordinary units, so `1.3 m / 75.2 cm` still produces the bit-identical result `TestUnits.testQuantityMaths` asserts.
