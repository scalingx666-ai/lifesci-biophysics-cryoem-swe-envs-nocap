### [`v3.3.0`](https://redirect.github.com/pypa/cibuildwheel/releases/tag/v3.3.0)

[Compare Source](https://redirect.github.com/pypa/cibuildwheel/compare/v3.2.1...v3.3.0)

- 🐛 Fix an incompatibility with Docker v29 ()
- ✨ Adds `test-runtime` option, to customise how tests on simulated/emulated environments are run ()
- ✨ Adds support for new `manylinux_2_35` images on 32-bit ARM `armv7l`, offering better C++20 compatibility ()
- ✨ `build[uv]` is now supported on Android ()
- ✨ You can now install extras (such as `uv`) with a simple option on the GitHub Action ()
- ✨ `{project}` and `{package}` placeholders are now supported in `repair-wheel-command` ()
- 🛠 The versions set with `dependency-versions` no longer constrain packages specified by your `build-system.requires`. Previously, on platforms other than Linux, the constraints in this option would remain in the environment during the build. This has been tidied up make behaviour more consistent between platforms, and to prevent version conflicts. ()
- 🛠 Improve the handling of `test-command` on Android, enabling more options to be passed ()
- 📚 Docs improvements ()
