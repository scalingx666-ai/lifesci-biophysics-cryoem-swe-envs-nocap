# Issue

**Title:** Round dt to integer indices instead of truncating

## Description

`Parser.create_integer_dt` used `.astype(int)`, so `0.3 ps / 0.1 ps = 2.9999999999999996` became index 2. A user-supplied `dt` of `[0.3, 0.7, 2.3] ps` gave indices `[2, 6, 22]`, so each MSD was computed at a different interval from the one it was labelled with. The fix rounds before casting.

**Tests:** `test_parser.py::test_parser_dt_index_inexact_float`.
